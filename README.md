InvokeAI Auto-Sorter

English Documentation | Deutsche Dokumentation
🇬🇧 English

An intelligent automation script designed to automatically sort, verify, and correct image assignments in your database based on metadata (LoRA filenames, internal tags, and prompts) generated by InvokeAI.
🚀 Features

    Smart Prioritization (LoRA/Tag over Prompt): Prioritizes technical truths (loaded LoRA files and embedded metadata tags like [PEOPLEZIT]) over potentially outdated prompt keywords.

    Fuzzy & Normalized Matching: Automatically handles typos, case sensitivity, German umlauts (ä -> ae, etc.), and file extensions (.safetensors, .ckpt).

    Self-Healing Sorting: Detects images that were misassigned to the wrong board (e.g., due to leftover prompt text) and automatically pulls them back into their correct technical board.

    Fallback Protection: Automatically assigns unassigned images to a configurable fallback board while protecting manually curated boards.

    Dry-Run Support: Test your sorting rules safely without modifying your actual database.

📋 Requirements

    Python 3.8+

    SQLite3

    tqdm (for progress bars)

🛠️ Installation & Usage

    Clone the repository and place invokeai_auto_sorter.py in your project directory.

    Ensure your database path and board configurations match your local setup.

    Run the script in Dry-Run mode first to preview changes (Dry-Run mode is the default without command arguments):
    Bash

    python invokeai_auto_sorter.py

    Run the live sorting process:
    Bash

    python invokeai_auto_sorter.py

🇩🇪 Deutsch

Ein intelligentes Automatisierungsskript zur automatischen Sortierung, Validierung und Korrektur von Bildzuweisungen in deiner Datenbank, basierend auf den von InvokeAI generierten Metadaten (LoRA-Dateinamen, interne Tags und Prompts).
🚀 Features

    Intelligente Priorisierung (LoRA/Tag vor Prompt): Technische Fakten (geladene LoRA-Dateien und Metadaten-Tags wie [PEOPLEZIT]) haben immer Vorrang vor potenziell veralteten Prompt-Schlüsselwörtern.

    Toleranter Namensabgleich: Gleicht Tippfehler, Groß-/Kleinschreibung, deutsche Umlaute (ä -> ae, etc.) sowie Dateiendungen (.safetensors, .ckpt) vollautomatisch aus.

    Selbstreinigende Sortierung: Erkennt Bilder, die durch alte Prompt-Reste in falschen Boards gelandet sind, und zieht sie zielsicher in das technisch korrekte Board zurück.

    Fallback-Schutz: Sortiert unzuordenbare Bilder in ein definiertes Fallback-Board ein und schützt gleichzeitig bestehende Zuordnungen.

    Dry-Run-Modus: Teste alle Verschiebungen vorab sicher, ohne dass an deiner Datenbank Änderungen vorgenommen werden.

📋 Voraussetzungen

    Python 3.8+

    SQLite3

    tqdm (für den Fortschrittalken)

    Passe die Datenbankpfade und Konfigurationen an deine lokale Umgebung an.
